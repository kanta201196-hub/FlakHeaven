## 5. Что автоматизируем
- Публикация Reels, фото и каруселей через Meta Graph API (облако до него достаёт, проверено 21.10). Нужен токен и публичный адрес файла: видео временно кладу на хостинг сайта, после публикации убираю.
- Обрезка клипов в 9:16 и субтитры (ffmpeg).
- Недельный отчёт по метрикам через API инсайтов.
- Расписание: триггеры по графику (пн, ср, сб), публикация только утверждённых текстов.
Не автоматизируется: создание аккаунта, Страница Facebook, приложение Meta, первый токен, сторис, ответы чужим людям без «да».

## 6. Риски
- Graph API публикует только в «Профессиональный» аккаунт, привязанный к Странице Facebook; токен живёт ~60 дней, продлеваю по графику.
- Юридическая сторона и доступность Instagram в регионе — решение Kanta; обходов не делаем.
- Новый аккаунт без истории: первые 1–2 недели не звать ссылками и не массово лайкать, иначе ограничат.
- Fake-подписчики и накрутка не используются.
- Музыка: только CC0/CC-BY, иначе Instagram заглушит ролик.
