# Discord-сервер Flak Heaven

Создан 20.10.2026 по решению Kanta ("давай сегодня сделаем дискорд"). Настроен ботом Flak Heaven Bot через Discord REST API. Тексты правил и приветствий одобрил Kanta (20.10.2026).

## Ссылка-приглашение
https://discord.gg/VmSepr2Wge — бессрочная, без лимита использований, ведёт в канал «сборки».

## Структура
| Категория | Каналы | Кто пишет |
| --- | --- | --- |
| НОВОСТИ | правила, анонсы | только владелец |
| ТЕСТЫ | сборки | только владелец |
| ТЕСТЫ | отчёты, баги, идеи | все |
| ИГРА | общее, скриншоты | все |
| ENGLISH | announcements | только владелец |
| ENGLISH | chat, feedback | все |

Все каналы видны всем. Роли «Разработчик» и «Тестер» — без особых прав, выдаёт Kanta вручную (цвет и отдельная строка в списке участников).

## Закреплённые сообщения
- «правила»: шесть правил (по делу, формат баг-репорта, без рекламы, вымышленный мир, игра только с itch.io, сборка тестовая).
- «сборки»: приветствие со ссылкой на https://kanta2011.itch.io/flak-heaven, сайт и Telegram.
- «announcements»: то же по-английски.
Тон — как в `voice.md`: от «я», без вопросов к читателю. Ссылка на itch.io в Discord допустима (в Telegram-канале её нет по решению Kanta).

## Бот
Flak Heaven Bot. Токен — переменная среды `DISCORD_BOT_TOKEN` (в репозиторий не кладём). Бот не может менять права собственной роли, поэтому «Администратор» с него снимает Kanta вручную: Настройки сервера → Роли → Flak Heaven Bot → Права → выключить «Администратор» (достаточно: управление каналами, ролями и сообщениями, просмотр, отправка, создание приглашений).

## Не сделано
- Функции «Сообщество» (экран правил при входе) не включены: не нужны на старте, включаются позже в настройках сервера.
- Ссылка на сайте и в itch.io — после «ок» Kanta, ставит тред сайта.
