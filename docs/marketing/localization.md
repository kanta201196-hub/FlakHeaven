# Перевод игры на другие языки

Нужен для широкого круга тестеров и для Steam. Проверено 18.10.2026.

## Где мы сейчас
- Все тексты игры написаны по-русски прямо в коде и сценах: в `game/scripts` кириллица есть в 79 файлах, около 4 400 строк, системы перевода (`tr()`) нет ни одного раза.
- Значит, перевод — сначала **переделка кода** (вынести тексты в таблицу), потом сам перевод. Это работа программиста на несколько дней, догадка по объёму; точную оценку даст пробный проход по файлам.

## Какие языки нужны
По данным Valve (доклад GDC 2025, пересказ [GamingOnLinux](https://www.gamingonlinux.com/2026/10/steam-survey-for-september-2026-shows-a-drop-in-linux-with-simplified-chinese-rising/)) китайский (упрощённый) и английский примерно равны (по 33 % пользователей), русский на третьем месте (около 8 %). Месячные опросы сильно скачут. Рекомендуемый набор по важности:
1. **Английский** (обязательно, это язык магазина и тестеров из-за границы).
2. **Русский** (уже есть, наше преимущество: русские игроки просили русский у конкурентов).
3. **Упрощённый китайский** (самая большая доля пользователей и жанр там популярен).
4. Затем по выбору: немецкий, французский, испанский, португальский (Бразилия), турецкий, польский, японский, корейский. Начинать стоит с трёх первых.

## Как сделать (технически)
Godot умеет таблицы перевода: [CSV или gettext (.po)](https://docs.godotengine.org/en/4.2/tutorials/i18n/localization_using_gettext.html); для работы в Git удобнее `.po`, для начала проще CSV. Шаги:
1. Все тексты → ключи (`tr("KEY")`) и одна таблица `game/locale/`.
2. Выбор языка в меню (по умолчанию — язык системы).
3. Шрифты: нужны гарнитуры для китайского (иначе знаки не отобразятся) и проверка длинных слов (немецкий).
4. Тексты в картинках (подписи на иконках) вынести в движок.
5. Страница Steam и описание — отдельно, на тех же языках.
6. Тест длины: в интерфейсе английский обычно длиннее русского.

## Как перевести (варианты)
| № | Вариант | Цена | Качество | Рекомендация |
| --- | --- | --- | --- | --- |
| 1 | Перевод нейросетью (Claude и др.) + выборочная проверка носителем из сообщества | 0 | хорошее для интерфейса, слабее для шуток и названий | да для английского и тестовых языков |
| 2 | Тестеры-носители переводят/правят в таблице (Discord, Google Таблица, Weblate/Crowdin — бесплатно для открытых проектов, **проверить**) | 0 | хорошее, растёт с сообществом | да, как второй слой |
| 3 | Платный перевод агентством (цена за слово — проверить, ведёт Kanta/Kirill) | деньги | лучшее | позже, для китайского, если игра пойдёт |
| 4 | Только английский + русский на старте, остальное добавить после | 0 | — | **рекомендую для первого теста** |

## Рекомендация
1. Задача в бэклог: «Подготовить перевод»: вынести тексты в таблицу (программист), добавить выбор языка.
2. Сделать **английский сразу** нейросетью, дальше проверка носителем из сообщества.
3. Китайский — после Next Fest; к странице Steam — английский + русский, остальное по желанию.
4. Для внешних тестеров: в записке и инструкции добавить английскую версию (`tools/tester/INSTRUCTIONS_*` и `SAFETY_NOTE_ru.txt`).
5. Правила названий: имена техники и биомов — единая таблица терминов, чтобы переводы не расходились.
