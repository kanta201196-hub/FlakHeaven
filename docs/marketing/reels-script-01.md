# Рилс-ролики: разбор образца и два сценария

Подготовлено 24.10.2026 по просьбе Kanta («изучи и проработай, как сделать такие же ролики»). Образец: рилс https://www.instagram.com/reel/DetI8WICF-Z/ (автор manohin_nocode, 20.10.2026, 45 с, вертикаль 1080×1920, около 19 тыс. лайков). Берём приём, а не персонажей и шутки: всё своё.

## Как устроен образец (по кадрам, шаг 2 секунды)
Сцена: тёмная «сцена» с бегущим кодом на фоне, два блочных 3D-персонажа (человек в кепке и оранжевый «Клод» на ножках). Говорят по очереди, крупные планы, белые субтитры по центру, реплика 5–10 слов, смена плана каждые 2–3 секунды. Выражение лица персонажа — одним-двумя пикселями (грусть, радость), без сложной анимации.

| Секунды | Что происходит | Приём |
| --- | --- | --- |
| 0–2 | «Клод, глянь этот рилс.» | хук: бытовая просьба, сразу понятная ситуация |
| 2–10 | «Я не умею открывать Инстаграм» → «Установи Agent Reach, это бесплатно» | проблема и простое решение, зритель узнаёт себя |
| 10–28 | Клод открыл рилс, комментирует; «Хочу поставить лайк!» — «Нельзя, он умеет только смотреть» | повторение с нарастанием: «А можно ещё один?» |
| 28–40 | «Клод. Прошёл час.» — «Я посмотрел сорок один рилс» | поворот: время ушло, герой не остановился |
| 40–45 | «Последний. Честно.» и общий план с обоими | концовка-петля: смотрится по кругу |

Почему работает: понятная ситуация в первую секунду, диалог вместо монолога, юмор из характера героев, шутка-повтор, концовка, после которой хочется пересмотреть.
