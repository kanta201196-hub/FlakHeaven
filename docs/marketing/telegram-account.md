# Аккаунт проекта в Telegram (задача из promo-plan, раздел 8, пункт 2)

Зачем: Bot API не пишет в чужие каналы и комментарии. Чтобы публиковать «Скриншотник» и отвечать в чатах без рук Kanta, нужен отдельный обычный аккаунт и вход через Telethon (библиотека для аккаунтов). Секреты среды: `TG_API_ID`, `TG_API_HASH`, `TG_SESSION`.

## Что проверено
- `api_id` и `api_hash` берутся на https://my.telegram.org → «API development tools». Свои ключи обязательны: чужие ключи — частая причина бана (документация Telethon). Ключи привязаны к номеру, секретные.
- Строка входа (StringSession) создаётся один раз скриптом `tools/telegram/tg_login.py` на компьютере Kanta: нужен код из Telegram/SMS (и пароль двухэтапной защиты, если включён). Дальше код не нужен, пока сессию не завершат.
- Код входа в чат присылать нельзя: Telegram считает это утечкой и может заблокировать вход. Поэтому вход делает Kanta сам, на своём ПК, одним запуском скрипта. Получить код в мой сеанс безопаснее и проще не получится.
- Правила чатов (смотрел публичные страницы): `@make_game` («GameDev: разработка игр», ~7,6 тыс.) — «Субботний скриншотник» идёт комментариями к посту, пример https://t.me/make_game/2155; ссылки на свои каналы разрешены, других правил на странице нет. `@indie` («Indie Spotlight», ~18,4 тыс.) — страница не упоминает скриншотник; заявки игр идут через закреплённый пост и чат @indieSpotChat. Перед первым постом скрипт `tg_post.py rules <чат>` покажет описание и закреплённые сообщения, прочитаю их.
- Что не проверено, и это догадки: точные лимиты Telegram для нового аккаунта (официально не публикуются). Обычные признаки риска: новый номер, вход с другого IP (облако, не домашний), сразу ссылки в чужих чатах.

- Не проверено: достаёт ли облако до серверов Telegram. Telethon говорит с Telegram своим протоколом (MTProto), не обычным HTTPS. Пробу подключения защита среды заблокировала, обходить не стал. Проверим на шаге 1 после «готово» (`whoami`); если не пройдёт, поправим сеть среды или публикует Kanta вручную. Обычный HTTPS до `api.telegram.org` работает (бот канала), но это другой путь.

## Риски и как их снижать
- Вход из облака с другого IP, чем при создании сессии, может насторожить Telegram. Поэтому: сессию создаём на ПК, аккаунт «прогреваем» 2–3 дня (профиль с фото и описанием, подписка на несколько каналов, пара реакций вручную с телефона), и первый пост не раньше чем через 2–3 дня после входа.
- Не более 3 публикаций в сутки (зашито в скрипт), пауза 20–60 с перед отправкой, при FloodWait скрипт останавливается.
- Только комментарии там, где это разрешено правилами; без массовых рассылок и личных сообщений незнакомым.
- Telegram запрещает спам, но разрешает обычное общение; автоматизация публикаций аккаунта — серая зона. Если аккаунт ограничат, потеряем только его, не канал проекта и не личный аккаунт Kanta.
- Вариант без риска: Kanta публикует «Скриншотник» сам с телефона (2 минуты раз в неделю). Мой совет: аккаунт всё равно завести, но 24.10 первый пост сделать вручную с аккаунта проекта или личного, а автоматику включать после прогрева.

## Инструкция для Kanta (21.10)
1. Купи или возьми отдельную SIM/номер, на который придёт SMS (не личный номер).
2. Поставь Telegram на телефон, нажми «Начать общение» (Start Messaging), введи этот номер, введи код из SMS.
3. Имя: «Flak Heaven», в «Настройки» → «Изменить профиль» (Settings → Edit Profile) поставь фото (логотип игры) и в «О себе» (Bio): «Roguelike про боевую авиацию. Первая игра, делаю в свободное время. flakheaven.com».
4. «Настройки» → «Конфиденциальность» (Privacy) → «Облачный пароль» (Two-Step Verification) → задай пароль и запомни его.
5. Открой https://my.telegram.org в браузере, введи номер аккаунта проекта, введи код, который придёт в Telegram.
6. Нажми «API development tools», заполни: App title — `FlakHeaven`, Short name — `flakheaven`, Platform — `Desktop`, остальное пусто. Нажми «Create application».
7. Выпиши `App api_id` и `App api_hash` (в чат не присылай).
8. На ПК проверь Python: открой терминал (Windows: Win+R, `cmd`), набери `python --version` (нужен 3.9 или новее; нет — скачай с https://www.python.org/downloads/).
9. Набери: `pip install telethon`
10. Скачай файл https://github.com/kanta201196-hub/FlakHeaven/blob/main/tools/telegram/tg_login.py (после слияния PR) — кнопка «Download raw file».
11. В терминале: `python tg_login.py` (в папке, куда скачал).
12. Введи `api_id`, затем `api_hash` (при вводе символы не видны, это нормально).
13. Введи номер в формате `+7...`, затем код из Telegram, затем облачный пароль из шага 4.
14. Скрипт выведет длинную строку. Скопируй её целиком, одной строкой.
15. Открой «Настройки проекта» (Project settings) → облачная среда → «Сетевые секреты» (или «Переменные среды») и добавь три значения: `TG_API_ID`, `TG_API_HASH`, `TG_SESSION`. Кладём в «Переменные среды» (Environment variables), не в скрипт настройки среды.
16. Напиши мне «готово». Новые переменные видят только новые треды; я открою новый тред для проверки.
17. Строку из шага 14 после добавления удали из буфера и истории терминала. Если подозреваешь утечку: Telegram → «Настройки» → «Устройства» (Devices) → «Завершить все остальные сеансы».

## Что делаю я после «готово»
1. `tg_post.py whoami` — проверка входа (только чтение).
2. `tg_post.py rules @make_game` и `@indie` — читаю правила.
3. Для публикации «Скриншотника» 24.10 в 12:00 МСК показываю тебе текст и кадр, запускаю без `--send`, жду твоё прямое «да» на конкретное действие, после этого `--send`.
