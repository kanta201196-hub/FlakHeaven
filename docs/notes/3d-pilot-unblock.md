## Варианты обхода

### Передача файлов (выбрать один)
1. **Прикреплять GLB прямо в этот тред.** Файл попадает в общую папку проекта, Claude забирает его сразу. Ни Диска, ни настроек. *Рекомендую для пилота.*
2. **Создать папку 3D_inbox на Диске** — ты сама или Claude через подключённый Диск (нужно твоё «да»). Удобно для пачек по 8–10 моделей на этапе 3.

### Генерация (можно сочетать)
A. **Разрешить облаку доступ к Hugging Face** (одна настройка): Настройки проекта → Cloud environment → шестерёнка → Network access → в Allowed domains добавить `huggingface.co` и `hf.space` (галочку «Allow package managers» оставить). Тогда Claude сам вызывает TRELLIS.2 (MIT, коммерция разрешена) по API, без твоих кликов. Это законная настройка своей среды, а не обход ограничений. Риск: очередь и квота бесплатного Space. *Рекомендую.*
B. **Ты генерируешь в браузере** (базовый план): Hunyuan 3D Global или TRELLIS.2, ~5–8 мин на модель, GLB — сюда в тред. Нужно для Hunyuan в любом случае: у него нет бесплатного API, и условия/доступ из России проверяешь ты на сайте.
C. **Модели кодом для простых форм.** Наземная техника (корпус + башня + ствол), ракеты, бомбы, НАР, подвесы — низкополигональные модели, собранные кодом в Godot. Части раздельные с рождения (решает риск «модель одним куском»), никаких лицензий и сервисов. Для самолётов хуже — их оставляем нейросети.
D. ~~Claude через встроенный браузер на твоём ПК~~ — в этом треде браузерных инструментов нет, поэтому сейчас недоступно.
