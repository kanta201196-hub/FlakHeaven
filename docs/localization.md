# Перевод игры на другие языки

Тред «Перевод игры», 18.10.2026. Статус: **решено** (Kanta 18.10, рекомендованные варианты: английский первым, переводит Claude, файлы `.po`, позывные по смыслу). Задачи L-01…L-05 в `docs/backlog.md`.

## Что сейчас в коде
Опись делает `python3 tools/i18n/scan_strings.py` (таблица всех строк: `--csv out.csv`).
- Все тексты написаны по-русски прямо в коде (`game/scripts/*.gd`), перевода нет нигде: ни `tr()`, ни таблиц перевода.
- **~1475 разных строк, ~7400 слов.** Больше всего в `profile.gd` (ангар, детали, позывные), `hud_screens.gd`, `cards.gd`, `menu.gd`, `plane_classes.gd`. Часть — отладка (`main_debug.gd`, `tuning.gd`, панель настройки): её не переводим.
- Почти весь интерфейс рисуется вручную (`draw_string` в `hud_*.gd`), поэтому автоматический перевод узлов Godot не сработает: каждую строку нужно явно обернуть в `tr()`.
- **23 места, где русский текст — ключ в логике** (`src == "НАР"`, `who == "ПВО"`, `callsign == "Барон"` и т. п., список печатает скрипт). Эти же слова пишутся в лог тестовой сборки и в сохранения («эвакуация» в рекордах). Поэтому их **не меняем**: внутри игры слова остаются русскими, переводится только то, что выводится на экран (правило ниже).
- Шрифты Inter, Exo 2, PT Sans покрывают латиницу и кириллицу. Для китайского, японского, корейского нужен ещё шрифт (например Noto Sans SC, лицензия OFL, бесплатно), сборка вырастет примерно на 10–17 МБ (оценка).
- Русские формы слов («1 карточка, 3 карточки, 5 карточек») требуют поддержки множественного числа.

## Варианты

### Какие языки
1. **Английский сейчас, остальные перед Steam** (рекомендую). Английский открывает почти всех внешних тестеров. Следом — упрощённый китайский (в Steam его доля примерно равна английской, ~33 %, см. `docs/marketing/localization.md`), потом немецкий, испанский, португальский (Бразилия), французский, японский.
2. Английский и сразу 2–3 языка тех тестеров, которых уже нашли.
3. Сразу 6–8 языков. Дорого в проверке: каждый текст меняется почти каждый день.

### Чем переводить
1. **Claude переводит сам по глоссарию, носители из тестеров проверяют** (рекомендую). Бесплатно, в рамках подписки; глоссарий держит одинаковые названия техники и оружия.
2. Добровольцы-переводчики через бесплатную площадку (Weblate, Crowdin). Бесплатно только для открытых проектов — условия проверить; имеет смысл после Steam, когда есть сообщество.
3. Профессиональное бюро. Платно, только решением Kanta или Kirill и ближе к выпуску, когда тексты устоятся.

### Как хранить переводы
1. **Файлы gettext `.po`, ключ — русская фраза** (рекомендую). Godot 4.4 читает их сам и сам собирает список строк из `tr()` (шаблон `.pot`). Поддерживает множественное число (`tr_n`) и пометку смысла, если одно слово значит разное. Файлы открываются в бесплатной программе Poedit и на площадках перевода.
2. Таблица CSV (`game/locale/strings.csv`), одна колонка на язык. Проще открыть в Google Таблицах, но нет множественного числа.
3. Латинские ключи (`ui.menu.start`) вместо русских фраз. Надёжнее при правке текстов, но придётся переписать все ~1500 строк и код станет хуже читаться.

### Названия и позывные
Позывные самолётов и асов («Грач», «Кит», «Барон», «Молот»):
1. **Переводить по смыслу** (Rook, Whale, Baron, Hammer) (рекомендую): игрок понимает образ.
2. Оставить русскими латиницей (Grach, Kit): звучит экзотично, но смысл теряется.

## Главное правило: переводим на выводе
Ключ перевода — русская фраза, как она написана в коде. Переводится строка только в момент вывода на экран; внутри игры (сравнения, лог, сохранения) слова остаются русскими. Так перевод не ломает бой, лог `l5` и старые сохранения.
- Общие функции вывода переводят сами через `Loc.out()`: `_text`, `_para`, чипы в `hud_kit.gd`, `_txt` и `_wrap` в `menu.gd`, всплывающие надписи `fx.text`, подписи над целями (`draw_string` в `boss`, `fortress`, `tanker`, `transport`, `rival_ace`, компас миникарты). `Loc.out()` в нерусских языках меняет «ёлочки» на “лапки”. Ширину текста (`get_string_size`) меряем у уже переведённой строки, иначе съезжает центровка.
- Строка с числами или склейка переводится до подстановки: `Loc.t("Прочность %d / %d") % [hp, max_hp]`, `Loc.t("Нужно: ") + x` (`game/scripts/loc.gd`), иначе ключ не найдётся. Так уже сделано в `hud_*`, `menu`, `profile`, `main` (баннеры), описаниях карточек (L-03).
- Не переводятся при создании (только на выводе): названия взятых карточек (`cards_log` — в логе тестера), текст отчёта тестера организатору, источники урона. Названия карточек с уровнем («Бронеплиты (1 → 2)», «Пушка: улучшение») переводит `Loc.title()` по шаблонам `TITLE_FORMATS` в `loc.gd`: новый шаблон названия карточки — добавить туда.
- Шаблон перевода: `python3 tools/i18n/scan_strings.py --pot game/locale/messages.pot` (1342 строки без отладки).
- Перевод: `game/locale/en.po`, подключён в `project.godot` (`locale/fallback="ru"` — без перевода показывается русский). Термины — `docs/glossary-en.md`.
- Проверка перевода против кода: `python3 tools/i18n/check_po.py game/locale/en.po` — новые строки без перевода, лишние и ошибки в `%d`/`%s` (ошибка подстановки = код выхода 1). Новые строки дописываются в `en.po` тем же тредом, что их добавил, или тредом «Перевод игры».
- Язык: «Настройки» → «Игра» → «Язык»: авто (ru/uk/be/kk → русский, иначе английский) / Русский / English. Хранится в `settings.json` (`lang`, −1 — авто).

## Китайский (L-05)
Черновик сделан 19.10.2026 (Kanta: «делай»). Перевод — Claude по глоссарию `docs/glossary-zh.md`, до Steam его проверяет носитель (ищет Kanta).
- Язык: «Настройки» → «Игра» → «Язык» → «简体中文»; авто-выбор включает китайский, если язык системы китайский.
- Перевод: `game/locale/zh_CN.po`, проверка — `python3 tools/i18n/check_po.py game/locale/zh_CN.po` (как для английского, `--sync` для новых строк).
- Шрифт: Noto Sans SC (SIL OFL 1.1), урезанный до знаков из перевода — `game/fonts/noto_sans_sc_subset.ttf`. Подключён запасным к любому шрифту интерфейса (`Hud.make_font`), поэтому иероглифы видны при любом выборе шрифта в настройках. **После каждой правки `zh_CN.po` запускать `python3 tools/i18n/subset_font.py`**, иначе новые иероглифы покажутся квадратами.
- Переносы: `draw_multiline_string` переносит китайский сам (данные ICU включены в экспорт: `include_text_server_data`), свой перенос `_wrap` в `menu.gd` для китайского режет между иероглифами.
