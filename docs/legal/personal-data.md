## PD-01. Яндекс Форма «Flak Heaven — заявка тестера» (делает Kanta, ~15 мин)
1. Открыть https://forms.yandex.ru → «Создать форму» (войти в Яндекс ID).
2. Название: «Flak Heaven — заявка тестера». Описание: «Тестовые сборки Flak Heaven для Windows и Mac. Нужно 30–60 минут, 3–5 вылетов и честный отзыв. Имя и контакт нужны только чтобы прислать сборку.»
3. Вопросы (как в Tally):
   - «Как к вам обращаться (имя в сети)» — короткий ответ, обязательный.
   - «Контакт: Telegram @ник или почта» — короткий ответ, обязательный.
   - «Система» — один из списка, обязательный: Windows 10/11; macOS (Apple M); macOS (Intel); Другая.
   - «Видеокарта и процессор (если знаете)» — короткий ответ.
   - «Сколько часов в неделю играете» — один из списка: до 5; 5–15; больше 15.
   - «Какие игры любите» — несколько из списка: roguelike; Vampire Survivors и похожие; аркадные шутеры; авиасимы; почти не играю в такое.
   - «Откуда узнали о нас» — один из списка: Telegram; Max; VK; Discord; Reddit; друг; сайт; другое.
   - «Согласие» — галочка, обязательная, текст ниже.
4. Текст согласия (вставить в галочку):
   «Я согласен(на) получить тестовую сборку и отправлять отчёты о ней, а также даю согласие на обработку моих данных из этой формы (имя в сети, контакт, ответы) для связи по тестированию игры Flak Heaven, как описано в политике конфиденциальности flakheaven.com/privacy. Согласие действует до конца закрытых тестов, отозвать его можно сообщением в Telegram t.me/FlakHeaven.»
Форма создана 19.10.2026: https://forms.yandex.ru/u/6ad66df2c45c0770823c7c1e/

5. «Опубликовать» → скопировать ссылку и прислать в тред «Сайт». Claude поменяет кнопку «Стать тестером» на сайте, политику (Tally → Яндекс Формы, ООО «Яндекс», Россия) и ссылки в `docs/testers/` и постах.
6. Старые заявки Tally: выгрузить и перенести в ответы Яндекс Формы/таблицу, затем удалить в Tally (PD-05, только с «да» Kanta).

## PD-02. Уведомление РКН (делает Kanta, ~30 мин, бесплатно)
Где: https://pd.rkn.gov.ru/operators-registry/notification/form/ (можно войти через Госуслуги — тогда подпись не нужна). Значения полей:

| Поле | Что вписать |
| --- | --- |
| Тип оператора | Индивидуальный предприниматель |
| ФИО, ИНН, ОГРНИП, адрес регистрации | данные ИП Kanta (не храним в репозитории) |
| Контакты | hello@flakheaven.com (после PD-03), телефон ИП |
| Цель обработки 1 | Организация закрытого тестирования компьютерной игры Flak Heaven: связь с участниками, отправка тестовых сборок, сбор отзывов |
| Цель обработки 2 | Ответы на обращения пользователей сайта flakheaven.com и игры |
| Категории ПДн | Иные: имя пользователя (псевдоним), контактные данные (адрес электронной почты, имя пользователя в мессенджере), ответы анкеты, сведения о компьютере (ОС, видеокарта) |
| Специальные и биометрические | не обрабатываются |
| Категории субъектов | Лица, подавшие заявку на тестирование; лица, обратившиеся к оператору |
| Правовое основание | Согласие субъекта ПДн (п. 1 ч. 1 ст. 6 152-ФЗ); ст. 6, 9, 18.1 152-ФЗ |
| Действия | Сбор, запись, систематизация, накопление, хранение, уточнение, использование, удаление, уничтожение |
| Способ обработки | Смешанная, с передачей по сети Интернет |
| Меры безопасности (ст. 18.1, 19) | Назначен ответственный (сам ИП); опубликована политика; доступ к аккаунтам сервисов только у оператора, вход с двухфакторной аутентификацией; данные удаляются по достижении целей |
| Ответственный за организацию обработки | сам ИП (ФИО, контакты) |
| Средства шифрования (криптозащиты) | не используются |
| Местонахождение базы данных | Россия, ООО «Яндекс» (сервис Яндекс Формы) |
| Трансграничная передача | нет |
| Дата начала обработки | дата публикации Яндекс Формы (PD-01) |
| Срок или условие прекращения | достижение целей обработки (окончание тестирования) или прекращение деятельности ИП |

После подачи РКН вносит оператора в реестр (обычно до 30 дней); номер записать сюда.

## PD-03. Почта hello@flakheaven.com (делает Kanta, ~3 мин)
Токену Claude не хватает прав на почтовую переадресацию, поэтому в панели Cloudflare (пункты по-английски, как на экране):
1. https://dash.cloudflare.com → домен **flakheaven.com** → слева **Email** → **Email Routing** → **Get started**.
2. Custom address: `hello` → Action: **Send to an email** → Destination: твоя Gmail → **Create and continue**.
3. В Gmail открыть письмо от Cloudflare и нажать **Verify email address**.
4. Вернуться в Cloudflare → **Add records and enable**.
После этого Claude проверит записи MX и впишет адрес на сайт и в политику.
