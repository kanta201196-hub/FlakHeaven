# Документы Flak Heaven

Здесь лежат все рабочие документы проекта, чтобы любой участник (и его Claude) видел то же, что и команда в проекте Claude.
С 16.10.2026 папка `docs/` в репозитории — общий источник правды для этих документов. Кто меняет документ, меняет его здесь (через PR в `main`).

## С чего начать
1. `game-context.md` — решения по игре и журнал решений. Читать перед любой задачей.
2. `concept/game-concept.md` — концепция игры целиком: жанр, вылет, классы, враги, прокачка, интерфейс.
3. `backlog.md` — бэклог и текущий спринт; `status-log.md` — отчёты по сборкам.
4. `roadmap/roadmap-2026-10-16.pdf` — план спринтов 6–20 (19.10.2026–16.05.2027).

## Что осталось только в файлах проекта Claude
Тяжёлые и рабочие файлы в репозиторий не кладём. Если в документе стоит путь `/mnt/project-files/...`, файл лежит там:
- тестовые сборки (`builds/`), сырые модели Meshy и GLB (`pilot3d/`, `biome3d/`), файлы Blender (`.blend`);
- скриншоты сравнений (`visual-audit/`, `hangar3d/*.jpg`, `turrets3d/`), портреты экипажа в полном размере (`progression/portraits/`; в игре они уже есть);
- личные логи плейтестов (`playtest/3.4-t1/*.csv`) — по правилам репозитория их не коммитим;
- переписка в тредах проекта.
