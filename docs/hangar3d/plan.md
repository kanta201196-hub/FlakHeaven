# 3D-ангар: план (правки 1, 3, 37 по тесту 3.4-t1)

## П. 1 — самолёт в ангаре в 3D (делаю сразу)
- Вкладка «САМОЛЁТ»: вместо картинки — объёмная модель Meshy максимального качества (решение 14.10: ангар и крупные планы — максимум).
- Мышью: зажать и тянуть — вращение; колесо — приближение; двойной щелчок — вернуть вид.
- Переключатель «Ур. 1 / Ур. 2». Ур. 2 показывается всегда; если не куплен — подпись «Не куплен, в вылет недоступен».
- На модели видно оружие, которое сейчас стоит на узлах подвески.
- Размер сборки: модели самолётов сейчас исключены из экспорта (архивы 88 и 113 МБ). Для ангара нужны 6 моделей; текстуры ужимаю до 2K, ожидаемо +25–35 МБ к архиву.

## П. 3 — оружие в 3D, вид меняется с уровнем (нужно ваше «да»)
Предлагаю у каждого оружия три ступени вида: ур. 1, ур. 3, ур. 5 (по веткам прокачки). Примеры:
| Оружие | Ур. 1 | Ур. 3 | Ур. 5 |
| --- | --- | --- | --- |
| Ракеты В-В | обычная ракета | крупнее, на пилоне | тяжёлая, с ускорителем (по решению 15.10 «1 ракета с точки» ракеты не множатся) |
| НАР | малый блок | большой блок | два блока |
| Бомбы | 2 бомбы | 4 | кассета |
| Пушечный контейнер | 1 ствол | 2 ствола | 3 ствола и кожух |
| Турель | одноствольная | спарка | спарка с щитком |
| Ловушки | малый кассетник | большой | два |
| Форсированный двигатель (ваш пример; такого модуля в игре пока нет) | обычное сопло | шире, с кольцом | шире, синее пламя форсажа |
Модели — кодом из простых форм (как постройки кишлака), без затрат кредитов Meshy.

## П. 37 — точки стрельбы (нужно ваше «да» + координация)
- Каждый модуль на самолёте получает точку вылета: ракета стартует с её пилона, очередь — из ствола контейнера, турель стреляет из своей башни.
- Модули появляются на самолёте по мере прокачки, у каждого свой угол (турель поворачивается к цели).
- Код выстрелов — в файлах треда «Итоги теста 3.4-t1» (weapons.gd, projectiles.gd). Я даю точки (функция «где у этого узла ствол» в мире), они подключают. Через координатора.
