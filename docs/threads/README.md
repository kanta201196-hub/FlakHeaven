# Выжимки тредов проекта Claude

Переписка в тредах проекта Claude у Kirill видна только там. Здесь — выжимки по каждому треду, где обсуждались решения: что решено (с датой и кто), что отклонено и почему, открытые вопросы, текущее состояние и где лежат файлы. Составлено 17.10.2026.

- Время в выжимках — UTC (МСК = UTC + 3).
- «Kirill» — владелец проекта, как в `CLAUDE.md`. Сообщения владельца в проекте Claude приходят с аккаунта «Ekaterina», поэтому в журнале решений (`docs/game-context.md`) решения владельца с 14.10 подписаны «Ekaterina».
- Пути `/mnt/project-files/...` — файлы проекта Claude у Kirill (тяжёлые: модели, .blend, скриншоты, сборки). Опись — `/mnt/project-files/export/heavy-files-inventory.md`, архив для Kanta — `/mnt/project-files/export/for-kanta-*.zip`.
- Источник правды — по-прежнему `docs/game-context.md` (журнал решений) и `docs/backlog.md`. Если выжимка с ними расходится, верны они.
- Новый тред с решениями → новая выжимка здесь или строка в существующей.
