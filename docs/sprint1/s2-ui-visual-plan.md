# S2 — Интерфейс и «объём»: план арт-директора

Дата: 11.10.2026 · Основа: прототип 2.8, отзыв Kirill от 10.10 (п. 1 «нужен объём», 3 «низкое разрешение», 9 «не видны подвесы», 10 «интерфейс, логика как у Sublight, стиль свой»).
Промпты к этому плану: `sprint1/chatgpt_prompts_ui.md`.

**Идея стиля одной фразой:** приборная доска и лётный планшет. Тёмный графит панелей, янтарная подсветка шкал, красные метки (как у врагов) только для опасности и запретов, срезанные углы, линейки-шкалы, «заклёпки». От Sublight берём **логику экранов** (меню → ангар → выбор → вылет → итоги), а не внешний вид: у них космический неон и скетч, у нас авиаприбор, трафарет и пустынная пыль.

## 1. Карта экранов

```
Главное меню ──► Ангар ──► Выбор самолёта ──► ПОЛЁТ (HUD)
     │            │  ├ Самолёт                   │  ├ Карточки уровня (при level-up)
     │            │  ├ Пилот (экипаж)            │  ├ Пауза / подвесы (Tab/Esc)
     │            │  ├ Оружейная (запчасти)      │  └ Итоги вылета ──► Ангар
     │            │  ├ Снаряжение                │
     │            │  └ Запреты                   │
     └──► Настройки (игра / графика / звук / управление) — доступны из меню и паузы
```

Обозначения: **Есть** — что уже в 2.8; **Код** — что делает программист; **ChatGPT** — что генерирует Kirill (промпт № из `chatgpt_prompts_ui.md`).

### 1.1 Главное меню
- **Назначение:** вход в игру, атмосфера, рекорды.
- **Блоки:** логотип; кнопки «Вылет» (основная, янтарная), «Ангар», «Настройки», «Выход»; журнал полётов (рекорды); версия; фон — живой биом со звеном.
- **Есть:** всё, кроме логотипа-картинки и кнопки «Ангар». Заголовок нарисован системным шрифтом Bahnschrift — **его нельзя поставлять в Steam** (шрифт Windows, лицензия не на распространение), заменить на OFL (см. 2.2).
- **Код:** вставить `ui_logo.png` вместо текстового заголовка; кнопка «Ангар»; лёгкое «дыхание» янтарной подсветки основной кнопки (0,6→0,9 альфы за 2 с); звуки наведения/клика.
- **ChatGPT:** логотип «FLAK HEAVEN» (№ 17). Фон остаётся живым — генерировать не нужно.

### 1.2 Ангар (хаб между вылетами)
Один экран с вкладками сверху (как «Настройки», тот же код вкладок). Слева — список вкладок/разделов, по центру — самолёт на стоянке (вид сверху, спрайт из игры), справа — карточка деталей. Внизу — счётчик запчастей и кнопка «К вылету».

| Вкладка | Назначение | Блоки |
|---|---|---|
| **Самолёт** | открыть/выбрать класс и его модернизацию | спрайт ур. 1/2, шкалы-линейки (прочность, скорость, манёвр, огонь), навык класса, «стоимость открытия» |
| **Пилот** (экипаж) | постоянные бонусы и характер | портрет, позывной, уровень пилота, 2–3 перка (напр. «+5% к перезарядке»), строка юмора-биографии |
| **Оружейная** | прокачка за запчасти (мета-прогресс, аналог исследований Sublight) | дерево/сетка ячеек-иконок 6 оружий + модули; ячейка: иконка, ур. N/5, цена; заблокированные — серые с красной меткой-замком |
| **Снаряжение** | стартовые подвесы перед вылетом | схема самолёта сверху с точками подвесов → клик → список оружия с иконками; подсветка группы на схеме |
| **Запреты** | исключить карточки из пула (за запчасти, ограниченное число) | сетка иконок карточек; запрещённые перечёркнуты красной диагональю (#D93D2E) |

- **Есть:** валюта «запчасти» (падает с врагов и позиций ПВО); механизм запретов/блокировки в пуле карточек (`banned`, `locked` в `cards.gd`); спрайты самолётов и подвесов. Экрана ангара нет. Нужно уточнить у программиста, сохраняются ли запчасти между вылетами.
- **Код:** экран-ангар на тех же примитивах `_panel` / `_menu_button` / `_ruler` из `menu.gd` (вынести их в общий `ui_kit.gd`); сохранение мета-прогресса в `user://`; самолёт по центру — реальный спрайт с тенью и медленным поворотом ±5°.
- **ChatGPT:** фон ангара (№ 16), портреты пилотов (№ 13–15), иконки (№ 1–12).

### 1.3 Выбор самолёта перед вылетом
- **Назначение:** быстрый выбор класса и пилота на этот вылет.
- **Блоки:** 3 карточки классов (Оса / Грач / Кит): спрайт, имя, роль одной строкой, 4 шкалы-линейки, навык; выбранная — янтарная рамка и самолёт «приподнимается» (тень сдвигается, масштаб 1,05); внизу — портрет пилота и кнопка «На взлёт».
- **Есть:** экран выбора класса (`hud.gd: _class_select`) — текст и полосы в старом сине-белом стиле.
- **Код:** перекрасить в стиль меню (графит/янтарь, срезанные углы), шкалы заменить на линейки с делениями, добавить портрет пилота. **Это первое, что стоит сделать** — экран виден каждый вылет и сейчас выбивается из стиля меню.
- **ChatGPT:** портреты (№ 13–15).

### 1.4 HUD в полёте
- **Назначение:** читаемость в хаосе; ничего лишнего в центре.
- **Блоки и места:**
  - верх-центр: полоса опыта + уровень, таймер вылета;
  - верх-лево: прочность (сегментная шкала, при < 30% — красная пульсация), навыки (Бочка / Форсаж / навык класса) — круглые индикаторы перезарядки;
  - верх-право: запчасти, сбито, угрозы;
  - низ-центр: **полоса подвесов** (см. раздел 4);
  - края экрана: стрелки на асов/эвакуацию/позиции ПВО (красные — угроза, янтарные — цель).
- **Есть:** всё перечисленное в виде текста и прямоугольников; полоса подвесов с картинкой, уровнем, перезарядкой и связками; стрелки на краях.
- **Код:** перевести панели HUD на графитовые подложки со срезанным углом (полупрозрачные 0,7, чтобы не закрывать бой); цифры — моноширинным шрифтом (не прыгают); строку подсказок управления скрывать после 60 с первого вылета (настройка «Подсказки»).
- **ChatGPT:** иконки навыков — можно взять из набора № 1–12 (бочка/форсаж — дорисовать кодом стрелками).

### 1.5 Карточки уровня
- **Назначение:** выбор улучшения за 2–3 секунды.
- **Блоки карточки:** рамка по редкости (цвет + число «заклёпок»: 1–5), иконка 128 px сверху, название, категория мелким капсом, описание 2 строки, полоса «ур. N → N+1» делениями. Внизу экрана — «Переброс (R)» и «Запретить» (красная метка).
- **Есть:** карточки, 5 редкостей с цветами, связки легендарной карточкой, переброс.
- **Код:** рамка = 9-slice из `ui_card_frame.png`, окраска `modulate` под редкость (одна картинка → 5 цветов); иконка из набора; появление карточек — сдвиг снизу 0,15 с со шлейфом; легендарная — медленный блик по рамке.
- **ChatGPT:** рамка (№ 18 — одна серая база, рекомендовано; № 19 — 5 цветных вариантов, если окраска кодом не понравится), иконки (№ 1–12).

### 1.6 Пауза / подвесы
- **Назначение:** передышка + обзор сборки.
- **Блоки:** слева — схема самолёта сверху **крупно** (тот же спрайт × 3) с подсвеченными группами подвесов и выносками-подписями; справа — список групп (иконка, оружие, ур., ×слоты), модули с уровнями, связки (открытые — янтарные, доступные — контур); кнопки «Продолжить», «Настройки», «В меню».
- **Есть:** пауза со списком групп текстом и кнопками «Настройки»/«В меню».
- **Код:** схема с выносками (линия от точки подвеса к подписи); наведение на строку списка → пульсирует соответствующая группа на схеме.
- **ChatGPT:** не нужно (используем спрайты самолётов и иконки).

### 1.7 Итоги вылета
- **Назначение:** «лётная книжка» — гордость и мотивация следующего вылета.
- **Блоки:** штамп-исход («ЭВАКУИРОВАН» янтарным / «СБИТ» красным, трафарет, лёгкий поворот −4°); время, уровень, сбито по типам (иконки врагов-миниатюры), урон по оружию (горизонтальные шкалы), полученный урон по источникам, заработано запчастей; кнопки «В ангар», «Ещё вылет».
- **Есть:** экран итогов с таблицей урона и списком карточек текстом.
- **Код:** штамп (текст шрифтом заголовков в рамке, анимация «удар» 0,1 с + звук печати); список карточек → ряд иконок с цветными точками редкости вместо длинной строки.
- **ChatGPT:** не нужно.

### 1.8 Настройки
- **Есть (2.8):** вкладки Игра / Графика / Звук / Управление, переназначение клавиш, ползунки, открытие из меню и паузы.
- **Код:** добавить «Масштаб интерфейса» (90–130%), «Подсказки», «Тряска экрана», «Контур подвесов» (вкл/выкл), «Язык» (RU/EN — понадобится для Steam).
- **ChatGPT:** не нужно.

|---|---|---|

**Редкости карточек** (свой вариант вместо «игровой радуги», приглушённый под графит):

| Редкость | Hex | «Заклёпки» |
|---|---|---|
| Базовая | `#A9AEB5` сталь | 1 |
| Обычная | `#7FBF5F` оливково-зелёный | 2 |
| Уникальная | `#5AA6E0` приборный голубой | 3 |
| Исключительная | `#B07AE8` фиолетовый | 4 |

Легендарная специально **оранжевее** янтарного акцента интерфейса, чтобы не путать «выбранное» с «легендарным». Красный в редкостях не используем — он занят под опасность.

### 2.2 Шрифты (бесплатные, OFL, нужна кириллица)
Проверить онлайн из этой сессии не получилось (нет доступа в сеть), поэтому ниже — по памяти; **перед подключением открыть страницу шрифта на Google Fonts → фильтр «Language: Cyrillic» и файл `OFL.txt` в архиве.**

| Роль | Вариант A (рекомендую) | Вариант B | Кириллица |
|---|---|---|---|
| Заголовки, кнопки, штампы | **Russo One** — жирный «технический» гротеск | **Tektur** — угловатый, «приборный», есть начертания по толщине | Russo One — уверен, есть. Tektur — почти уверен, проверить |
| Текст, описания карточек | **PT Sans Narrow** (ParaType, OFL) — узкий, отлично читается в кириллице | **IBM Plex Sans Condensed** | обе — уверен, есть |
| Цифры HUD (не прыгают) | **PT Mono** | **IBM Plex Mono** | обе — уверен, есть |

**Про трафарет.** Хороших бесплатных *трафаретных* шрифтов с кириллицей я не знаю: популярные Black Ops One, Saira Stencil One, Big Shoulders Stencil, Allerta Stencil, по моим данным, только латиница. Поэтому:
1. логотип «FLAK HEAVEN» — картинкой из ChatGPT (№ 17), там трафарет нарисован;
2. заголовки на русском — Russo One + «трафаретные перемычки» кодом: 1–2 вертикальные щели цветом фона поверх букв в крупных заголовках (≥ 36 px) — простой шейдер или `draw_rect` по маске; на мелком тексте перемычки не делать.

Размеры (при 1920×1080): H1 48, H2 30, кнопки 22, текст 18, подписи 14 (капсом, разрядка +1). Минимум для текста — 14 px, иначе на Steam Deck не читается.

### 2.3 Иконки
- Монохромные, **плоская заливка одним цветом**, без градиентов, вырезы-«трафаретные» прорези для деталей; толщина штриха одинаковая во всём наборе.
- Исходник 1024 от ChatGPT → в студии спрайтов уменьшить до **512** (хранение), в игре показывать 128 (карточка), 48 (полоса подвесов), 32 (список).
- Цвет в игре задаёт код: оригинал янтарный; неактивная = обесцвечено + 40% альфы; запрещённая = янтарь + красная диагональ; наведение = +15% яркости.
- Имена: `i_<id>.png`, где id совпадает с кодом (`aam`, `rockets`, `bombs`, `gunpod`, `flares`, `turret`, `armor`, `engine`, `wing`, `reload`, `wingman`, `repair`).

## 3. «Объём» (п. 1 отзыва)

### 3.1 Что уже сделано (2.6–2.8)
- Высокие объекты (гора, скалы, крепость, оазис) — **слои-экструзия**: несколько копий спрайта сдвигаются к камере по высоте → «растут» навстречу при пролёте.
- **Тени по высоте**: у самолётов и объектов, в одну сторону (свет сверху-слева).
- **Облака** с параллаксом (2 слоя) и **их тени** на земле (`CloudShadows` в `clouds.gd`) — пункт «тени облаков» уже закрыт, дальше только доводка.
- **Взрывы**: вспышка, огненные шары, дым, обломки, искры, ударная волна, выжженные пятна.
- **Псевдокрен**: при повороте самолёт сужается по ширине до 55% (`player.gd`, `bank`).
- Не вышло: экранный слой «атмосфера» (свет/дымка/виньетка) ломал GL Compatibility — убран.

### 3.2 Следующие шаги

| # | Приём | Что даёт | Сложн. | Эффект | Нужно от ChatGPT |
|---|---|---|---|---|---|
| 1 | **Крен самолёта 5 кадрами** (−2, −1, 0, +1, +2) | самый заметный «объём» — самолёт ложится на крыло, видна нижняя поверхность и подвесы | M | ★★★ | да: 4 доп. кадра на класс×уровень = 24 картинки. Риск — ChatGPT плохо держит идентичность между кадрами. **Сначала пробуем кодом:** сужение + сдвиг верхнего/нижнего крыла (skew) + затемнение опущенного крыла градиентом. Если мало — генерируем только ±2 (крайние), промежуточные — смешиванием |
| 2 | **Пыль от взрывов на земле** | наземные цели «на земле», а не на картинке | S | ★★★ | нет — кольцо светло-охристых частиц, расходится по земле, без подъёма; цвет берётся из текстуры биома под точкой |
| 3 | **Тепловое марево у форсажа** | «реактивность», ощущение скорости | S–M | ★★ | нет — шейдер искажения UV по шуму за соплом. **Важно:** в GL Compatibility экранный `SCREEN_TEXTURE` уже подвёл; делать **локально** (маленький `BackBufferCopy` на хвост) и проверить на слабой видеокарте. Запасной вариант — полупрозрачные дрожащие «линзы» из частиц |
| 4 | **Тени облаков — доводка** | глубина без затрат | S | ★★ | нет — затенять не только землю, но и самолёты/врагов, когда проходят под тенью (−20% яркости) |
| 5 | **Карта нормалей для объектов** | объекты освещаются «боком» от вспышек взрывов, рельеф гор и крепостей | M–L | ★★ | можно: ChatGPT умеет «height map»/«normal map» по картинке, но **результат нестабилен** (не совпадает пиксель-в-пиксель). Надёжнее: попросить у ChatGPT **height map** (серое: белое = выше), а нормали считать в студии спрайтов (Собель по высоте). В Godot — `CanvasTexture` с normal map + `PointLight2D` от взрывов. В Compatibility 2D-свет работает, но каждый свет = доп. проход; ограничить 4–6 огнями одновременно |
| 6 | **Атмосферная перспектива слоёв** | дальше от камеры = чуть голубее и бледнее | S | ★ | нет — `modulate` по слоям, без экранного шейдера |
| 7 | **Тень самолёта с высотой** | при бочке/форсаже тень «отдаляется» и размывается | S | ★★ | нет |

**Рекомендуемый порядок:** 2 → 4 → 1 (кодом) → 3 → 7 → 5. Первые три — за один вечер программиста и закрывают ощущение «плоско» на 70%. Нормали — только после того, как всё остальное готово и есть запас производительности.

**Промпт для height map (если решим делать № 5)** — прикрепить готовый объект, например `o_mesa.png`:
> Create a grayscale height map of the attached top-down object for a 2D game. Pure white = highest point, pure black = ground level, smooth gradients for slopes. Keep the exact same silhouette, size, position and framing as the attached image, pixel-aligned. No shading from light, no texture details, no shadows. Transparent background outside the object. Square 1024×1024.

Сохранять как `h_<имя объекта>.png`. Проверка: наложить в студии на оригинал с прозрачностью 50% — контуры должны совпасть.

## 5. Порядок работ (предложение на спринт 2)

1. **Kirill (ChatGPT, ~1,5–2 ч):** лист иконок № 0 (или 1–12) → логотип № 17 → рамка № 18 → портреты № 13–15 → фон ангара № 16.
