## Новые колонки лога

Файл лога теперь `user://playtest_log_<сборка>_l2.csv` (новый набор колонок — новый файл). Колонки добавлены **в конец** строки, поэтому они же уходят в отчёт тестера (`run_row`) без изменений в Apps Script. Код — `game/scripts/telemetry.gd`.

| Колонка | Что | Для какой проверки |
|---|---|---|
| `log_ver` | версия набора колонок (`l2`) | отделить старые строки |
| `fps_avg`, `fps_low1` | средний FPS и FPS «1 % худших кадров» за вылет | A4, A5, производительность |
| `slow_frames` | кадров длиннее 50 мс | рывки |
| `fps_limit`, `vsync` | настройки игрока | сравнение FPS |
| `pad_s`, `kbm_s` | секунд с геймпадом / клавиатурой и мышью | A2, A3, B-11 |
| `scheme_changes` | смен схемы управления за вылет | A3 |
| `gun_rate_max` | максимальный темп курсового, выстр./с | A4 |
| `gun_multi_frames` | кадров, где курсовое сделало >1 выстрела (раньше эти выстрелы терялись) | A4 |
| `shots_lead`, `hits_lead` | выстрелы и попадания с упреждением | A1: точность упреждения |
| `lead_nosol` | случаев «встреча невозможна» | A1 |
| `swept_hits` | попаданий, которые старая проверка пропустила бы | A5 |
| `roll_uses` | бочек за вылет | B1 |
| `invuln_s`, `invuln_chain_max` | секунд неуязвимости всего и самая длинная непрерывная (бочка + после удара) | B1, A6 |
| `nm_through` | снарядов сквозь неуязвимость, не засчитанных «на волоске» | A6 |
| `hitstops`, `hitstop_in_slowmo` | стоп-кадров и их наложений на замедление | A10 |
| `speed_avg`, `speed_max`, `turn_max` | средняя и максимальная скорость (пикс./с), максимальный разворот (°/с) | рост скорости и манёвра, будущий эксперимент C1 |

## Как анализировать

1. Сравнить строки `l2` со строками 3.3-t2 того же класса: `dealt_gun_*` / `dealt_total`, `hits` / `shots`, уровень на 5:00, время открытия связок.
2. A4: `gun_multi_frames > 0` при `fps_avg < 60` — значит, раньше на этом ПК терялись выстрелы.
3. B1/A6: `invuln_chain_max` не должен превышать длительность бочки + 2 с (неуязвимость после удара).
4. `timeline` — построить кривые урона и FPS по минутам, отметить минуты открытия связок.
