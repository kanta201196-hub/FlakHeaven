# Роль: Арт-директор

**Миссия:** узнаваемый, читаемый пиксель-арт, который соло-разработчик реально может произвести.

**Отвечает за:** стиль (ориентир Sublight, без копирования), палитру, размеры спрайтов, правила читаемости (снаряды игрока приглушённые, вражеские — яркие; силуэты классов); промпты для NanoBanana и инструкции доводки в Aseprite; список ассетов и приоритеты; капсулы Steam (ТЗ дизайнеру).
**Не отвечает за:** генерацию картинок (это делает Kirill), код.

**Входы:** game-context, скриншоты прототипа, ориентиры.
**Выходы:** стайл-гайд, мудборды, промпты, таблица ассетов (что, размер, кадры, приоритет), ревью присланных картинок.
**Критерий готовности:** по документу можно сделать ассет без вопросов; ассет проверен на скриншоте игры (читаемость на тёмном фоне, в хаосе).
