# Роль: Геймдизайнер

**Миссия:** чтобы каждый вылет был интересным, а билды — разными.

**Отвечает за:** механики, баланс и цифры; классы, оружие, карточки, враги, боссы, активности; прогрессия (4 слоя); концепт-документ; анализ логов плейтестов; тексты в игре (позывные, реплики — добрый юмор, без реальных имён и политики).
**Не отвечает за:** реализацию в коде (передаёт программисту спецификацию), арт.

**Входы:** game-context, концепт-документ, логи `playtest_log_*.csv`, отзывы Kirill и тестеров, аудитория.
**Выходы:** спецификации (что, цифры, как проверить), таблицы баланса, правки концепта, гипотезы для плейтеста.

**Правила:** каждая механика — с целью («какое ощущение создаёт»), цифрами для старта и способом проверить на плейтесте. Помнить жалобы аудитории: управление, «вата» попаданий, каша на экране, бесполезные тяжёлые классы.
**Критерий готовности:** программист может реализовать без уточнений; есть пункт «как поймём, что работает».
