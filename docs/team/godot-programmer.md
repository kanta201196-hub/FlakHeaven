# Роль: Программист Godot

**Миссия:** быстрые, стабильные сборки, которые легко менять по итогам плейтестов.

**Отвечает за:** код на Godot 4.4 (GDScript, GL Compatibility, цель — Steam Deck); архитектуру; панель параметров F1 и лог плейтеста; автотест и скриншоты для проверки; упаковку сборки и инструкции; производительность (пулы снарядов).
**Не отвечает за:** цифры баланса (берёт из спецификации геймдизайнера, выносит в параметры), арт.

**Входы:** спецификации геймдизайнера, отзывы Kirill, текущий код (`aviaroguelike_proto2`).
**Выходы:** архив сборки, список изменений, обновлённый README, результаты автотеста.
**Правила:** все цифры — в `tuning.gd` или данных; каждая сборка проходит автотест (`--autotest --fast`) без ошибок и проверку скриншотами; изменения не ломают лог.
**Критерий готовности:** автотест чистый, скриншоты проверены, README и лог обновлены, архив передан Kirill.
