## 2. Предлагаемый процесс (один абзац на этап)

**Недельный ритм вместо спринта.** Пн: планёрка показывает «критический путь» (раздел 3) и очередь. Ср: середина, проверка лимитов. Пт 18:00 МСК: ревью работы. Сборка — не по календарю, а когда выполнено условие закрытия цикла.

**Цикл «замечания → сборка».**
1. Kanta присылает замечания; координатор собирает их в пронумерованный список в бэклоге (раздел «Правки по сборке N»).
2. После слова «готово» координатор раздаёт пункты по системам (одна система = один тред) и сразу называет модель и очередь.
3. Размер пункта: **малый** (один файл, число, текст) — делаем сразу, без плана; **средний** (несколько файлов одной системы, без новых правил игры) — короткий план в описании PR, без `docs/superpowers`; **крупный** (новая система, новый экран, изменение правил, затрагивает больше 3 систем или больше ~500 строк) — brainstorming → план в `docs/superpowers/plans/ГГГГ-ММ-ДД-имя.md` → исполнение, с «да» Kanta на план.
4. Проверка: `pick.sh` → smoke; менялся бой → один `full.sh`; менялось демо → ещё `--demo` smoke (см. п. 4 ниже). В PR строка «проверено: …».
5. Слияние Claude сам. Статус в бэклоге: **слито** (код в main), затем **проверено в игре** (Kanta или тестер). 
6. **Закрыт цикл** = все пункты списка в статусе «проверено в игре», «отложено решением Kanta» или «перенесено в следующий список с причиной». Только тогда сборка.

**Сборка.** По прямой команде Kanta, не раньше суток после предыдущей, сначала `smoke.sh all`, потом `make_kit.sh`. Лёгкая модель.

**Демо и Next Fest (критический путь).** Работа идёт в таком порядке, обратном от дат: 25.01 демо и страница на проверку ← 15.01 закрытый тест (Playtest) завершён ← 15.12 DM-05 и DM-06 ← 30.11 страница Steam и взнос ← 10.11 взнос $100 ← 01.11 регистрация. Заморозка демо с 01.02 — только исправления. Каждая неделя: сколько пунктов критического пути закрыто.

**После Next Fest до раннего доступа (новый блок).** 22.02–01.03 сбор отзывов и вишлистов (цель 2000 к старту); неделя после фестиваля — разбор в одном документе; март–апрель — доводка по отзывам, цена, описание страницы раннего доступа, дорожная карта для игроков; дата выхода ставится только после закрытого теста (догадка: апрель–май, как в журнале решений от 15.10).

**Роли и модели.** Старые роли-агенты (`docs/team/*.md`) остаются как справка, а не как процесс. Код/геймдизайн/3D — Opus (не больше двух), документы/маркетинг/сборки/логи — Sonnet, статусы — Haiku. Первым в очереди Opus идёт всё, что на критическом пути.

**Навык геймдизайна.** Когда тред навыка закончит, он ставится *перед* brainstorming для задач про правила игры, баланс, прокачку; для кода и графики не нужен.
